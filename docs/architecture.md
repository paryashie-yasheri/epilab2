# KUP-10 — Контур архитектуры

Компоненты MVP:

- витрина и личный кабинет — frontend;
- каталог, заказ и статусы — backend API;
- платёжный провайдер и поставщики товаров — внешние интеграции;
- база данных хранит товары, остатки, заказы и журнал операций.

Заказ проходит состояния `created → payment_pending → paid → fulfilled`.
Обработка callback идемпотентна: повторное уведомление не создаёт повторную выдачу.
